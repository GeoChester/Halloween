Time for YOU to work!

Each of the 16 caches in the Tricks&Treats series contains a clue. The clue is written on the logbook – some clues are numbers with a letter assigned (noted as: a = 1, b = 2, c = 3), and some clues are letters only.

Line the numbers up in two groups: abcde and vwxyz. Alphabetize the letters and enter them directly between the two number groups. No spaces, no commas or full stops; letter size is not important. The result will be 16 characters. For example, if: a = 1, b = 2, c = 3, d = 4, e = 5 and v = 6, w = 7, x = 8, y = 9, z = 0 and LETTER, the result would be: 12345EELRTT67890

Enter the 16 characters into the Certitude checker, and if you did it correctly, you will receive instructions on how to find the Halloween Bonus cache.
